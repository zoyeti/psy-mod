# Магистерская диссертация

**Автор:** Рудашевская Зоя Владимировна

**Научный руководитель:** Ковальчук Сергей Валерьевич, Гофман Ольга Олеговна

**Направление подготовки:** Математическое и компьютерное моделирование, Университет ИТМО

## Тема работы

**Математическое моделирование взаимосвязей психологических характеристик и профессионального выгорания при взаимодействии с искусственным интеллектом.**

_Формулировка рабочая и может уточняться по результатам аналитического обзора и разработки дизайна исследования._

## План работы

Период работы: ноябрь 2026 — июнь 2028 года.

| Период | Этап и ожидаемый результат |

| Январь — март 2027 | Аналитический обзор математических методов. Выбор моделей-кандидатов и критериев их сравнения. |
| Февраль — апрель 2027 | Разработка дизайна психологического исследования, выбор методик измерения и подготовка протокола сбора данных. |
| Март — май 2027 | Формализация модели, программная реализация и проверка на симулированных данных. |

_Контрольные точки для статей и докладов обозначают готовность материалов. 
Сроки подачи и выступлений будут уточняться по календарям журналов и конференций._

## Материалы репозитория

По мере выполнения работы здесь будут размещаться:

- аналитический обзор и библиография;
- исследовательские гипотезы и протокол исследования;
- математическое описание моделей;
- программный код и инструкции по его запуску;
- результаты моделирования и анализа;
- материалы публикаций и выступлений.
